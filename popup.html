    Claude Code

    In Claude Code say "Connect Codex Dev"; it gives you a 6-digit code to enter below. Connects to the MCP server on this computer (127.0.0.1). Claude Code can only inspect tabs you allow below. See mcp-server/README.md.

    First time? Register the server with Claude Code
    1. Build the server once, from the repo root:
      cd mcp-server && npm install && npm run build
    2. Register it with Claude Code. Shared with anyone who opens this repo (run from the repo root):
      claude mcp add --scope project codex-dev -- node mcp-server/dist/index.js
      Or just for you, from any folder (use the full path):
      claude mcp add codex-dev -- node /full/path/to/codex-dev/mcp-server/dist/index.js
    3. Check it with claude mcp list. It should show codex-dev as connected. For a project-scope server, Claude Code asks you to approve it the first time you run claude in that folder.
    4. Install the website-check skill (optional, once): Claude then checks breakpoints, fonts, accessibility and section spacing, and asks before fixing.
      node mcp-server/dist/index.js install-skill
    5. Then say "Connect Codex Dev" in Claude Code and enter the code below. Claude Code starts and stops the server itself, so you never run it by hand.

    This tab

    Allowing a tab attaches Chrome's debugger (you will see its banner) so Claude Code can set the viewport, take screenshots and read console and network errors. Authorization ends when you navigate to another site or close the tab.

    Then try: "Check my site with Codex Dev." Claude uses the same devices as the Responsive Viewer (iPhone 14 Pro, iPad Air, Desktop 1920×1080).
