Each install gets a daily number of free requests. They reset at midnight UTC.

What gets sent

Nothing is sent until you press send in the Codex AI chat, or Create animation in Design Inspector AI. Then your message, the selected elements' HTML and key styles, and for edits a screenshot of the selected area go to the Codex Dev server, which forwards them to Anthropic and returns the answer. The server does not store your message, HTML or screenshot. It keeps only a daily request count for your install and a hashed network address, to enforce the daily limit.
